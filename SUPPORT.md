# Support

Search [existing issues](https://github.com/ayushcmd/waytodoomsday/issues) and the
[documentation index](docs/README.md) before opening a new request.

| Request | Route |
| --- | --- |
| Setup or usage question | Read [README.md](README.md), then open an issue with a clear question |
| Reproducible site bug | Use the bug report in the [issue chooser](https://github.com/ayushcmd/waytodoomsday/issues/new/choose); include browser/device and steps |
| Feature idea | Use the feature request template; describe the problem and desired result |
| Cast, chronology or other factual correction | Use the content correction template with dated evidence, correct character/actor variant and proposed tier |
| Security vulnerability or exposed secret | Follow [SECURITY.md](SECURITY.md) privately |
| Harassment or conduct concern | Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Rights or attribution concern | Email [ayush_24a12res897@iitp.ac.in](mailto:ayush_24a12res897@iitp.ac.in) with the asset path/URL and rights information; avoid publishing private documents |

The on-site enquiry widget sends ordinary feedback to Formspree. It is not a
security reporting channel. Public issues and screenshots must not contain tokens,
personal data, exploit details or unmarked plot spoilers.

Watch progress stays in your browser's local storage; there is no account backup
or cross-device recovery service. Clearing site data may erase progress. Cast
evidence can change: an official preview is not a final-cut guarantee, and
speculation is not an announcement. This volunteer project has no guaranteed
support response time or promised release schedule.
